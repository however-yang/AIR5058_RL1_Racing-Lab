# 课程赛车物理与比赛规则

本版以 1.77 kg 的四轮教学车为对象，采用平坦、干燥的课程赛道。车轮半径 0.086 m，轴距 0.384 m，轮距 0.338 m。规则按统一的车辆版本应用于上海与斯帕。表中的执行器和摩擦参数是标定起点，标定通过后才冻结比赛版本并启动训练。

## 车辆和控制

| 项目 | 拟定规则与参数 |
| --- | --- |
| 控制频率 | 策略每 0.05 s 输出一次期望速度和转角。MuJoCo 每 0.01 s 更新执行器、轮胎接触和车辆状态。所有选手使用相同频率、积分器与车辆参数。 |
| 驱动 | 后轮电机驱动。期望速度范围为 0–5.0 m/s，速度参考上升率不超过 3.0 m/s²、下降率不超过 5.0 m/s²。后轮每轮驱动转矩从约 0.23 N·m 开始标定，随转速升高减小，空载转速上限从约 58 rad/s 开始标定。驱动力来自电机与轮胎接触。 |
| 制动 | 后轮制动转矩从每轮约 0.38 N·m 开始标定。转矩始终反抗车轮旋转，接近静止时平滑衰减。实际减速度随抓地力和载荷变化。策略可以松油、减速和停车。 |
| 车速 | 平地干燥赛道以 5.0 m/s 为额定上限。限速器根据实际车身平面速度削减驱动，持续超过 5.10 m/s 达 0.10 s 判为超速失败。5.10 m/s 是拟定的数值容差阈值，验收时应验证正常驾驶不会触发。 |
| 转向几何 | 使用前轮 Ackermann 转向。虚拟前轮转角限于 ±0.44 rad，左右前轮按共同的瞬时转弯中心计算各自的目标角。当前几何下满舵时，内外轮分别约为 0.536 rad 和 0.372 rad，后轴中心低速几何半径约为 0.82 m。各实体前轮目标角上限为 ±0.54 rad。 |
| 转向动态 | 左右轮目标角以共同转向几何为准逐步变化，任一目标前轮的变化速率不超过 2 rad/s。保留有限的舵机转矩和阻尼，并以 10 ms 采样验收实际转角速率。若实际转角速率持续越限，标定舵机增益、阻尼与力矩限制。 |
| 车身状态 | 每步位置、车头角度、车轮转速与速度由物理积分产生。策略通过转向与速度指令操控车辆。仅在回合开始时设置初始位姿。观测公开实际前轮角与速度，以及低层执行器当前的目标值，便于策略判断当前还能转多快、刹多快。 |

正向与制动转矩起点来自 $\tau\approx m a r/2$，用于估算静态量级。实际车辆响应需要测量轮胎滑移、电机转动惯量与载荷转移后的结果。超速记录用世界坐标系中的平面速度范数，避免侧向滑动被当成低速。

## 轮胎和抓地力

- 轮胎与赛道干地接触显式设定有效切向摩擦系数，初值 **μ = 0.90**。两个切向方向使用同一初值，采用 MuJoCo 椭圆摩擦锥和三维接触。车辆受重力与接触约束，轮胎失去法向载荷时，能传递的地面力相应下降。
- 同一个轮胎接触同时承担加速、制动和转弯。若纵横向摩擦系数相同，近似满足 $\sqrt{F_x^2+F_y^2}\leq\mu F_z$。在评分版参数冻结前，用运行时接触数据确认生效的系数和力。当前版本的轮胎填 1.45、地面填 1.20，同优先级接触实际测得 1.45。
- 车轮允许出现打滑。打滑、抱死及抓地力利用率记录为诊断量。车辆只要合法通过赛段，轻微滑移仍然是可评估的驾驶行为。无轮地接触时，转动驱动轮不会产生轮胎对地推进力。
- 抓地力应由接触模型产生。道路边缘的规则几何与可视化路肩分开，以可行驶区域判罚。

### 每个物理子步的抓地与滑移

1. 执行器只向舵机和车轮施加有限力矩。MuJoCo 在每个 **10 ms** 子步识别当前轮地接触，并按轮胎负载解出法向力和切向力。驱动、制动与转弯共同消耗同一份抓地力。车轮离地时，该轮的轮地作用力为零。
2. 干地正式版采用固定且明确的轮地接触参数，初始有效摩擦系数 **μ = 0.90**。标定时检查运行中的接触系数。赛道上的色带、发车线和路肩装饰共用路面的物理规则，车道外区域不能提供额外的可用抓地力或有效进度。
3. 车身按求解得到的合力、合力矩和惯性继续运动。抓地力不足时，轮胎可以相对地面滑动，实际轨迹可向外偏离。弯速公式用于选择验收工况和解释结果，实际轨迹由动力学决定。直道或足够宽缓的弯道允许满油门。
4. 记录轮地接触点的切向相对速度和抓地利用率。相对速度根据车轮接触点在世界坐标中的实际运动计算，包含轮子转动。接触力接近上限和实际滑动分别记录。擦边可纠正的滑移仍是合法驾驶，越界或翻车由统一判罚。
5. 各轮接触的摩擦力和滑移均按物理子步记录或汇总。轮速用于分析空转和抱死，车身实际位移用于计算进度和计时。油门指令、轮速与车身速度分别记录。

[MuJoCo 接触动力学](https://mujoco.readthedocs.io/en/stable/computation.html) · [定半径提速测量抓地力的教学实验](https://ddl.stanford.edu/content/classroom-asset-measuring-friction)

## 比赛判罚

1. 从统一发车区静止起步。固定种子控制小范围起始位置和航向偏移。每个回合限时 48 秒。
2. 每 10 ms 用车体与轮胎的水平投影检查边界。以车道边界为限，路肩按视觉设施处理。车体或轮胎越界则失败。车身侧倾或俯仰导致车身上轴与世界竖直方向夹角超过 60° 并持续 0.10 s，也判失败。数值误差和接触容差在冻结前统一标定。
3. 必须正向依次穿越 8 个检查点并回到终点。检查基于穿越方向和线段交点。重复跨线、逆向跨线与跳点不推进有效进度。判罚与终点发生在同一物理子步时，先判罚。超时回合按失败处理，保留最大合法进度。
4. 评分器固定车辆模型、轮胎、时间步、初始条件范围、赛道与检查线。学生提交策略，评测环境只接收两维合法指令。训练奖励由学生自行设计。正式完赛率达到 95% 后，按成功回合中位圈速比较，另报告出界、翻车、超速、超时与未完赛进度。
5. 官方排名使用固定干地条件和同一批留出起点。不同抓地力下的测试可作为独立的鲁棒性实验，分别报告结果。


6. 越界看当前合法赛段内的车辆外廓。任一车轮或车体投影跨出车道即失败，包括车辆暂时离地的情况。邻近赛段的路面不能替代当前赛段。官方车道边界、画线与评分几何需对齐。
7. 使用仿真时钟。开关渲染、机器快慢或推理设备不改变每次控制指令覆盖的仿真时间。过线时刻可在相邻物理子步之间插值。重置种子与车道、车辆、接触模型、执行器和求解设置由统一评分器控制。
8. 策略接口固定为两个有限数值的归一化指令。非法形状、NaN、无穷值或明显越出指令范围判作无效控制。车辆初态、外力、控制频率、计时和重置只由评分器设置。物理求解器异常单列为环境故障，由 TA 复核。

## 走线与候选奖励

平路、近似稳态时，沿实际行驶轨迹的横向加速度约为 $a_y=v^2/R$。若暂时不制动，弯速的粗略抓地力上限为 $v\lesssim\sqrt{\mu g R}$。按 μ = 0.90 估算，半径 1.5 m 的轨迹约为 **3.64 m/s**，半径 2.8 m 的轨迹约为 **4.97 m/s**。在弯中制动时，部分抓地力已经用于减速，能用于转弯的余量更小。较大的走线半径可以维持更高速度，也可能增加距离。连续弯还要为下一个弯保留出弯位置。

建议标定后比较两组奖励。A 组只用有符号赛道进度、用时和终局奖惩。B 组在 A 的基础上加轻量的贴边风险和轮胎饱和余量惩罚。两组都允许策略使用全部合法车道宽度。正向进度只奖励首次到达的合法位置，逆向仍按有符号进度扣分。这样重复倒车再前进只能回到已计过分的位置。高横向加速度本身可以是合法且快速的，利用率接近饱和时才出现风险代价。

B 组的试验起点：

```text
每步奖励 =
    2.0 × [新增的最大合法进度 + min(0, 有符号进度)]（米）
  − 0.35 × 本步用时（秒）
  − 本步用时 × [1.0 × 贴边风险² + 0.5 × 抓地饱和风险²]
  + 12（完赛） / −8（出界、翻车或超速） / −2（超时）
```

- **贴边风险**以车体与轮胎外缘到最近车道边界的最小净空为准。净空大于 0.15 m 时为零，更靠近边界时平滑增大，到边界处为 1。
- **抓地饱和风险**以每个有载荷接触的实际切向力除以该接触的 μFz。只累计利用率超过 0.85 的部分，并用 0.15 归一化，裁剪到 [0, 1]。按各接触的法向载荷和物理子步时间汇总，跳过低载荷接触以减少噪声。若验证发现这一项抑制合法高速过弯，调低权重或采用 A 组。
- 奖励中保留正向进度与时间成本，让较快的合法走线有回报。报告中比较刹车点、弯中最低速度、出弯速度、轨迹和分段用时，用来解释圈速差异。

## 冻结规则前的验收

| 测试 | 需要记录与通过的条件 |
| --- | --- |
| 直线全油门、全刹车 | 记录车身与后轮速度、转矩、到 4 m/s 的时间和制动距离。目标变化率符合限制，实际车速不触发超速线，停稳后没有主动反转。 |
| 静止与滚动时满舵反打 | 左右前轮各自记录角度和角速度。满左到满右需要明确的过渡过程。检查 Ackermann 转角关系和实际舵机响应。 |
| 低速圆与定半径提速 | 低速时检查内外轮角和后轴几何转弯半径。以约 1.5 m 和 2.8 m 的半径逐步提速，记录实际轨迹半径、横向加速度、接触力与失稳时的速度。 |
| 弯中制动与不同抓地力 | 比较同速转弯时加刹车前后的轮胎利用率、滑移和轨迹偏离。降低试验路面摩擦时，检查运行时系数和可用弯速随之下降。 |
| 合法与非法跑圈 | 验证边界、逆向穿线、跳点、超时、超速、翻车与正常完赛。确认固定种子可重复，开关渲染的评测一致。 |
| 全赛道可完成性 | 在两条赛道上用保守循迹策略跑公开起点，确认执行器限制、宽度和限时可兼容。物理与规则通过后才启动训练。 |


### 抓地专项验收

| 工况 | 验收标准 |
| --- | --- |
| 同一弯道的慢速与高速对照 | 用约 1.5 m 半径的标定弯。两组从相同入弯位置、航向进入，使用同一转向设定。以实测入弯速度约 3.0 m/s 和 4.5 m/s 做对照。低速组应能沿弯通过。高速组应出现更大的实际滑移或向外偏离。若在抓地不足时继续保持过高的实测速度并跨越边界，结果必须判为出界失败。 |
| 同速弯中加刹车 | 两次从相同弯中状态开始，分别保持油门和增加制动。记录轮胎纵横向力、法向载荷、滑移与轨迹，核验总切向力服从接触抓地预算。 |
| 改变路面系数 | 用正式干地设定和试验低抓地设定复跑同一工况。确认运行时的有效摩擦系数确实改变，低抓地下失去稳态跟弯能力的速度更低。 |
| 全程最大油门压力测试 | 用同一个能循迹的控制器，比较固定最大速度指令与弯前主动减速策略。确认至少有代表性的急弯让持续高速策略自然偏离或失败，同时保守策略能完赛。如果宽走线使最大油门也能合法过弯，这是有效走法。若课程需要考减速判断，应在冻结前调校代表弯的几何或车辆抓地。 |
| 数值稳定性 | 用 10 ms 和 5 ms 复核代表工况，保持同样的 20 Hz 策略频率、执行器参数和赛道。比较制动距离、转向响应和明显高低速工况的结局。若换步长会反转明显工况的结局，先排查接触参数、求解精度与边界检测。 |

训练阶段先固定上述版本，同一算法、交互步数和训练种子对照 A/B 奖励。以完赛率和中位圈速选模，辅以各弯的抓地利用率、边界净空和制动距离。留出起点只用于最终评测。

## 实现与首轮标定

控制器设定的前轮目标转角速率为 1.85 rad/s，为实际舵机响应留出余量。直线实测最高约 4.59 m/s。10 ms 与 5 ms 下的标定记录保存在 `physics_calibration.json`。上海用于策略训练和选模，斯帕用于已选模型的独立迁移验证。

## 赛车走线奖励的配对分段

相对同预算原多走线奖励。上海与斯帕均用各自的 40 个共同完赛干地起点。正值表示新奖励用时增加。

| 计时窗口 | 新奖励用时差 |
| --- | ---: |
| 上海整圈 | +20.9 ms |
| 上海螺旋弯至后直道末端 | +16.7 ms |
| 斯帕整圈 | +11.5 ms |
| 斯帕 Eau Rouge 至 Kemmel 直道末端 | +5.0 ms |
| 斯帕 Bruxelles 至下一段直道末端 | +7.2 ms |

本批次斯帕最快的是固定线续训版。低抓地的 39 个共同完赛起点上，新奖励比原多走线奖励慢 41.6 ms。该奖励对照只用了一个训练种子。

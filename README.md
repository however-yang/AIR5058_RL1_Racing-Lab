# AIR5058 RL1 · MuJoCo 赛车实验

用 PPO 或 SAC 训练四轮小车，在统一的车辆、抓地和判罚规则下尽快完成一圈。上海用于训练与选模，斯帕用于检验换赛道后的表现。学生可以从奖励占位函数开始设计自己的实验。 [学生作业说明](student/README.md) · [学生起步 ZIP](mujoco-racing-student.zip)

**最新同预算对照中，赛车走线奖励把上海低抓地完赛从 39/40 提到 40/40，干地整圈按同起点配对在上海慢 21 毫秒、在斯帕慢 12 毫秒。** 本轮斯帕最快的是固定线续训策略，完赛 40/40，中位圈速 26.247 秒。 [本轮逐回合数据](ta_private/racecraft_comparison/results.json)

## 测过哪些奖惩函数

| 奖励 | 设计 | 实验 |
| --- | --- | --- |
| 进度与终局 | 首次取得合法进度时给分，倒退和耗时扣分。完赛加分，失败和超时扣分 | PPO 基线 |
| 进度加风险 | 在进度奖励上增加低净空与轮胎高抓地利用率的代价。示范预训练组还对快速转向变化加入小幅惩罚 | 直接 PPO 与示范预训练 PPO |
| 单线剩余时间 | 每步扣实际耗时，失败额外扣分。用实测加减速曲线估计沿一条参考线到终点的时间，并用估计的变化提供训练信号 | 固定参考线 SAC |
| 多走线剩余时间 | 从当前位置、朝向、速度和实际转角出发，估算接入多条可行路线后的余程用时 | 同类固定参考线 SAC |
| 赛车走线奖励 | 多走线估计随抓地调整，弯后长直道的预计用时最多加权 30%。轮胎抓地利用率高且净空过小或转向过快时加入实测风险代价 | 与原多走线 SAC 同预算对照 |

各时间奖励沿用实际耗时和终局判定。弯心早晚、是否使用外侧车道以及前后弯如何衔接，由候选路线的预计用时决定。固定线续训与横向目标实验使用同一多走线奖励，主要比较控制方式。 [设计与公式](ta_private/DESIGN.md) · [训练入口](ta_private/train_remaining_time.py)

## 最新同预算奖励对照

两组 SAC 都用训练种子 101、8 个上海环境和 196,608 步，推理修正幅度相同。固定线续训策略是上轮存档参照。表格格式为「完赛数 / 总数 · 成功回合中位秒数」。

| 方案 | 上海干地 | 上海低抓地 | 斯帕干地 |
| --- | ---: | ---: | ---: |
| 原多走线剩余时间 SAC | 40/40 · 31.093 | 39/40 · 31.350 | 40/40 · 26.319 |
| 赛车走线奖励 SAC | 40/40 · 31.111 | 40/40 · 31.380 | 40/40 · 26.329 |
| 已冻结的固定线续训 SAC | 40/40 · 31.116 | 40/40 · 31.420 | 40/40 · 26.247 |

相对原多走线奖励，新版在上海螺旋弯至后直道末端慢 16.7 毫秒，斯帕 Eau Rouge 至 Kemmel 直道末端慢 5.0 毫秒，Bruxelles 至下一段直道末端慢 7.2 毫秒。以上为同起点逐圈差的中位数。奖励对照只用了一个训练种子，低抓地多完赛一圈还不足以判断改进能否复现。 [配对分段与冻结记录](ta_private/RESULTS.md#赛车走线奖励的配对分段)

## 其他实验成绩

### PPO 进度奖励与风险奖励

下表为各组代表检查点。三组训练上限均为 409,600 步。示范组增加了驾驶示范预训练。

| 方案 | 上海干地 | 上海低抓地完赛 |
| --- | ---: | ---: |
| 进度与终局 | 40/40 · 32.116 | 16/20 |
| 进度加贴边与抓地风险 | 40/40 · 31.943 | 19/20 |
| 示范预训练 + 进度与风险奖励 | 40/40 · 31.502 | 20/20 |

示范组通过上海选模后，在斯帕完成 40/40，中位圈速为 26.733 秒。更早一轮使用种子 7、13、23 的等预算 PPO 实验也记录了两种奖励的逐种子表现。 [PPO 原始结果](ta_private/best/results.json) · [早期多种子结果](ta_private/HISTORY.md#首轮物理规则版对照)

## 评测口径

较新的对照要求上海干地与低抓地都至少 95% 完赛，再按上海干地中位圈速选出代表，锁定权重后用独立斯帕起点复测。低抓地摩擦系数为 0.82。每个批次内部使用相同起点，跨批次的圈速用于记录进展。提速按同起点配对结果判断。 [评测设计](ta_private/DESIGN.md#选模与对比)
